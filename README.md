# Home Credit Risk Platform

End-to-end credit risk analytics and machine learning project based on the Home Credit Default Risk dataset.

## Project Goals

- Build a relational credit risk database with Microsoft SQL Server.
- Perform data quality checks and business analysis with SQL.
- Create dedicated SQL views for Power BI and machine learning.
- Develop end-to-end machine learning models.
- Build a credit risk decision engine.
- Explain predictions with SHAP.
- Serve models with FastAPI.
- Build an interactive Streamlit application.
- Report business and model results with Power BI.

## Technologies

- Microsoft SQL Server
- Python
- Pandas
- Scikit-learn
- LightGBM
- XGBoost
- CatBoost
- SHAP
- Power BI
- FastAPI
- Streamlit
